# Ijwi ry'Ikirundi AI 🇧🇮

**Ikirundi cacu, Ijwi ryacu!**  
*(Notre langue, notre voix !)*

Dataset et modèles ouverts pour le Kirundi.  
Initiative communautaire pour l'IA (ASR, TTS, MT).

### À propos

Nous créons les ressources open-source nécessaires pour :

- 🎙️ **Speech-to-Text (ASR)**
- 🗣️ **Text-to-Speech (TTS)**
- 🌐 **Traduction automatique**

### Nos piliers

| | Rôle |
| :--- | :--- |
| [**Kirundi_Dataset**](https://github.com/Ijwi-ry-Ikirundi-AI/Kirundi_Dataset) | Corpus texte + audio (~4,7k phrases) |
| [**kirundi-contribution-app**](https://github.com/Sama-ndari/kirundi-contribution-app) | App pour traduire et ajouter des phrases |
| [**nllb-kirundi-multi**](https://huggingface.co/Ijwi-ry-Ikirundi-AI/nllb-kirundi-multi) | Modèle de traduction KR ↔ FR / EN |

### Contribuer

1. [Application web pour contribution](https://sama-ndari.github.io/kirundi-contribution-app/) — Aucune compétence technique requise
2. Issues / PR sur les dépôts ci-dessus
